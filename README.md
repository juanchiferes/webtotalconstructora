# Total Constructora – sitio web

Sitio institucional estático (HTML + CSS + JS, sin dependencias) para Total Constructora, empresa de mantenimiento de edificios con 30 años de experiencia.

## Ver el sitio
Abrí `index.html` en el navegador, o servilo con `python3 -m http.server`.

## Personalizar
- **Datos de contacto:** editá el objeto `CONTACT` al inicio de `js/main.js` (WhatsApp, teléfono, email). Los valores actuales son de ejemplo.
- **Textos y servicios:** `index.html`.
- **Colores y tipografías:** variables al inicio de `css/styles.css`.

## Publicar
Al ser estático se puede subir a GitHub Pages, Netlify, Vercel o cualquier hosting.
